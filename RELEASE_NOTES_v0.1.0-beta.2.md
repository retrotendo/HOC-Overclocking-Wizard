# HOC Overclocking Wizard v0.1.0-beta.2

- Benchmark preparation now requires a true 100% battery reading while connected to the charger.
- Hardware Detection now shows the detected RAM class and its Expected Max OC range.
- Removed internal/developer-facing reference-console wording from Hardware Detection.
- Active Values are now context-aware: RAM tuning shows RAM/VDD2/VDDQ/SoC/DVB, GPU tuning shows GPU voltage plus RAM context, and CPU tuning shows the CPU voltage/UV/VMIN/TBreak/VMAX values relevant to the current stage.
- Hardware and benchmark setup pages no longer show an irrelevant generic active-values card.
