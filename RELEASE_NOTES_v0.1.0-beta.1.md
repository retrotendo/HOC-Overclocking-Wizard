# HOC Overclocking Wizard v0.1.0-beta.1

First experimental beta of the adaptive HOC Overclocking Wizard.

- independent OC app/state/updater paths
- orange/red beta52-derived graphical interface
- DRAM detection with HOC-informed Common/ST timing profiles
- RAM clock/performance sweep and graphing
- RAM HP/DVB/VDD2/VDDQ/SoC tuning stages
- embedded Benchmark Toolbox memory, GPU FPS and CPU Ray Trace FPS measurements
- GPU voltage/performance sweep and GPU + RAM integration validation
- CPU Low/High UV, TBreak, High VMIN and VMAX guided stages
- real-clock verification for capped CPU operation
- adaptive combined-failure backoff logic instead of fixed device values
- Stable Max / Sweet Spot / Recommended graph markers
- safety backup and final save to Performance Modes · OC Mode

This is an early testing beta. Keep a known-good No-OC boot path and current backups available.
